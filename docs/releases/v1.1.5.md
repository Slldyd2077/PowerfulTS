# PowerfulTS v1.1.5

本次统一发布此前 v1.1.4 后合并的 PR #21、#22，以及近期收藏和响度改动。

- 音乐响度使用快速测量，开播与分析并行；分析完成后用 5 秒平滑过渡到固定增益，不新增磁盘音频缓存。
- 搜索及歌单显示已收藏状态，按平台和歌曲 ID 区分；移除曲目或歌单后同步更新标记。
- 保留站内通话、RNNoise VAD、手机音频恢复和解码旁路；加入可选人声处理、实际说话状态及管理员频道/成员/音乐机器人频道管理。
- 音乐语音避让按解码 PCM 判断，静音语音包不会持续触发。

配套音乐引擎固定为 [`48577fe`](https://github.com/Slldyd2077/teamspeak-music-bot/tree/48577fe57984ca3522da092e614a30f2501b6455)。PowerfulTS 安装包仍不捆绑独立 TeamSpeak/TSMusicBot 服务，使用上述引擎源码构建，无需叠加历史补丁。

验证包括后端 388 项测试及 9 项 subtests、引擎 275 项回归、前端单元测试/类型检查/构建、收藏与歌单/响度/频道管理浏览器回归及发布打包测试。线上服务器 180 秒合成音源的测量由 33.46 秒降至 2.77 秒，此数字不代表 CDN 下载耗时。

可选 DeepFilter/SpEx+ 需要另行运行模型服务，不安装时仍使用本地 RNNoise；模型权重和私人录音不打入 Release。手机锁屏/后台仍受操作系统和浏览器限制。

选择与 CPU 对应的 Docker 安装包：Intel/AMD x64 使用 amd64，Apple Silicon/ARM64 使用 arm64；Windows 选 ZIP，Linux/macOS 选 tar.gz。需要 Docker 与 Compose v2.20 以上。下载后核对 SHA256SUMS，升级前备份并保留 backend.env 与 data/。
