# 管理员频道管理

管理员登录后有两个入口：

- 网页通话页，频道列表下方的“频道管理”。
- 音乐控制页，TS Bot 区域的“频道管理 · 所有机器人”。

面板可以创建永久频道及子频道，修改名称、设置或移除密码，删除空频道，移动在线成员。
“移除成员”会将目标踢出 TeamSpeak 服务器，需确认操作；不会删除网页账号或封禁，对方可以重新加入。
默认频道、含子频道或有成员的频道不能直接删除。操作权限由后台校验；普通成员与游客不能调用。
TS ServerQuery 账号还需要相应的 TeamSpeak 管理权限。

音乐机器人列表包含所有账号拥有的机器人，并显示所有者，不要求好友先共享。
网页通话身份不包含在这个列表里。管理员仅获得频道管理能力，不因此获得朋友的
平台账号、私人歌单或删除机器人权限。

选定目标频道和机器人后：

- “立即移动机器人”：更改当前频道，需要机器人在线，不改变默认频道。
- “保存默认频道”：使用频道 ID 保存，避免同名频道歧义；下次重连生效。
  如需现在也移动，再点击“立即移动机器人”。

不勾选更新密码会保留机器人已有的频道密码；勾选后留空会清除密码。
修改频道本身的密码采用相同逻辑。密码不从后端返回页面。
机器人需要连接到正在管理的同一台 TS 服务器；其他服务器的频道 ID 不通用。
音乐播放跟随开启时，后续点歌可能使机器人再次移动到点歌者所在频道。

验证包含后台 RBAC、频道密码保留/清除、删除保护、网页身份隔离、目标服务器检查，
以及浏览器移动/保存默认频道、新建表单、390 px 布局和普通成员隐藏入口。
实际服务器只做了读取验证，没有为测试修改用户频道或移动机器人。
