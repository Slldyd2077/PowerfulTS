# 一起看与屏幕共享

## 使用

1. 加入网页通话，进入目标 TS 频道，再点击「加入共享房间」。
2. 如果已有共享，直接接收当前视频状态或共享画面。每个频道按自己的 CID 隔离，包括母频道与子频道。
3. 如果没有共享，第一位发起者成为房主。选择网站视频同步、直链视频或屏幕 / 窗口共享。
4. 房主可以停止共享、调整等待和暂停权限，或转交给同频道已进入共享房间的成员。停止当前内容会保留房主身份，退出后释放。

房主转交同步视频时保留地址、倍速和进度。转交屏幕时结束旧画面，新房主点击屏幕共享重新授权自己的窗口。

## 同步观看

直链模式支持浏览器原生可播放的 MP4、WebM 等视频地址。普通视频网站的页面地址不属于视频直链。

网站模式通过配套 Chrome / Edge 扩展读取和控制 HTML5 视频。扩展只申请 `activeTab` 和 `scripting`，用户分别主动连接通话页和视频页，不读取登录 Token，不传输视频文件或 Cookie，也不会自动跳转视频标签页。

1. 下载通话页的 `watch-extension.zip`，解压。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，选择「加载已解压的扩展程序」。
3. 在 PowerfulTS 网页通话页点击扩展按钮，选择「连接通话页」。
4. 打开要看的视频标签页，点击扩展按钮，选择「连接视频页」。扩展找到视频后会在通话页填入地址。
5. 房主发起同步观看。其他成员打开房间的视频链接，用各自的扩展连接对应标签页。
6. 保持两个标签页打开。导航到另一视频后重新连接；不使用时点击扩展的「断开扩展连接」。

网站模式的观看发生在各自的视频网站标签页。每人使用自己的登录状态、会员权益、清晰度和音量，房间同步播放位置与倍速。视频标识保留路径、分集参数及未知查询参数，忽略常见分享追踪参数，避免把不同分集当成同一个视频。

当前支持同页面及开放 Shadow DOM 中的 HTML5 `<video>`。跨域 iframe、封闭 Shadow DOM、专用播放器、前贴片广告及平台改版可能需要额外适配；请在正片开始后连接。不绕过平台内容保护。未完成 B 站、腾讯视频、爱奇艺所有播放类型的实站验证，不能保证所有网页都可自动同步。

### 全屏、弹幕和清晰度

网站模式保留原平台页面及播放器，观众可以独立使用平台的全屏、弹幕开关与样式、清晰度、字幕和音量控件。清晰度选项取决于各自账号权限和平台支持，不与房主强制一致。切换清晰度后触发的加载与缓冲会报告给等待机制。

直链和屏幕模式提供「全屏观看」按钮及浏览器原生视频控件，按 Esc 或原生控件退出全屏。直链不自带平台弹幕或多码率选项。屏幕模式能够捕获房主播放器中显示的弹幕与控件，但观众接收的是房主画面，无法独立改变原播放器的清晰度和弹幕设置；希望各自调整时使用网站同步模式。

## 等待、暂停和断线

- 点播默认开启「等待成员加载完成」与「允许成员暂停」，房主可单独关闭。
- 有人缓冲、寻找视频或失去就绪心跳时，房间冻结进度；所有观看者恢复就绪后，按房主此前的播放意图继续。页面会显示等待谁。
- 成员暂停属于主动暂停，加载恢复不会自动撤销，需房主点击「继续播放」。成员可以在通话页暂停，也可以通过已连接的视频控件暂停。
- 掉线保留 20 秒，重连到同频道会恢复原共享身份，包括房主权限；超时移出等待。网页共享连接遇到普通网络断开时自动尝试重连，最多 5 次。
- 主动退出、切频道、挂断立即移出；上游掉线、登录过期和其他频道变化还有每 3 秒的服务端成员核验。
- 直播选择「这是直播」，加载等待不生效；屏幕共享一直按实时传输处理。

## 屏幕共享部署

生产环境使用 HTTPS；开发环境可使用 localhost。浏览器每次都会要求选择并授权共享对象。共享音频的支持取决于浏览器、操作系统和所选对象，受保护的视频可能出现黑屏。

网页通话继续使用原有 TSMusicBot 音频通道。屏幕内容使用独立的 WebRTC 连接，由分享者向每个观看者发送；PowerfulTS 后端仅转发信令、房间状态，不中继视频。当前每个房间最多 9 人（分享者及 8 位观看者），分享者上传带宽随观看人数增加。

默认配置 STUN，用于发现连接地址。跨运营商、对称 NAT 或受限网络通常需要自建 TURN。在后端环境变量中配置 JSON 数组并重启后端，例如：

```ini
SCREEN_SHARE_ICE_SERVERS=[{"urls":"stun:stun.example.com:3478"},{"urls":["turn:turn.example.com:3478?transport=udp","turns:turn.example.com:5349?transport=tcp"],"username":"your-user","credential":"your-password"}]
```

TURN 会在直连不可用时中继画面，需考虑带宽；凭据会提供给已认证的共享客户端，应使用专用账号。前端现有 `/api` nginx WebSocket 代理即可承载信令，不需开放新 HTTP 接口端口。屏幕音频与麦克风可能重复收音，优先共享单个标签页并戴耳机。

当前房间状态和一次性票据存储在单个后端进程内。请保持单 worker；多实例部署需要共享房间协调及票据存储。后端重启后共享房间清空，成员重新加入。

## 协议与验证

`POST /api/music/voice/watch/ticket` 通过 `X-Session-Token` 验证身份，核验当前通话 bot 所在频道，签发 30 秒一次性 WebSocket 票据。登录 Token 不进入 WebSocket URL。只有同频道连接能获取房间状态和互发屏幕信令，成员不能跨频道接管或发送视频控制。

验证包括：

- 后端房间与接口测试：单画面、父子频道隔离、首位分享者房主、转交、晚加入快照、一次性票据和来源检查、等待与直播例外、成员暂停权限、掉线宽限、心跳、容量及消息队列约束。
- 前端单元测试：时间偏差补偿、播放进度纠偏、倍速、自动播放被阻止；扩展视频标识、标签页绑定、就绪及暂停消息路由。
- 三个独立浏览器会话：使用生成的测试画面和本地 MP4，验证实际 WebRTC 画面传输、频道隔离、房主转交、缓冲等待、暂停权限、重新加入、全屏进入与退出、手机布局及浏览器运行错误；HTML5 测试页验证扩展同步和保留原页面控件。

这些测试不替代真实 TS / TSMusicBot 部署、多运营商网络和第三方平台的实机测试。
